# Ulsan_AR

울산 이벤트용 모바일 웹 AR 체험. 앱 설치 없이 브라우저에서 바로 실행되며, 퍼즐(이미지 인식)과
쓰레기줍기(손 인식) 두 가지 미니게임을 제공한다.

## 화면 구성

- **`index.html`** — 첫 화면. 배경 이미지 + 상단 중앙 로고 + 하단 중앙 "입장" 버튼.
- **`ar-scene/`** — 실제 AR 체험. 퍼즐(`index.html`)과 쓰레기줍기(`trash.html`)가 완전히 분리된
  페이지다(8th Wall이 이미지 트래킹 전용/월드 트래킹 켬 설정을 실행 중에 못 바꿔서 한 페이지 안에서
  전환할 수 없음). 상단 모드 버튼을 누르면 두 페이지 사이를 이동한다.
  - **퍼즐**: 카드 마커 4장을 카메라로 인식하면 화면 중앙 2x2 그리드가 하나씩 채워지고, 4개를 다
    모으면 완성 이미지가 화면에 표시된다.
  - **쓰레기줍기**: 실측 위치(월드 트래킹)로 3D 오브젝트 몇 개가 사용자 주변에 배치된다. 실제로
    걸어서 일정 거리 안까지 다가가면 그 오브젝트가 눈앞에 고정되고, 그 상태에서 손으로 쓰다듬는
    동작(짧은 시간 안에 방향이 여러 번 바뀌는 움직임)을 하면 오브젝트가 사라지며 진행 상황(N/5)이
    올라간다.
- **`assets/images/`** — 배경, 로고, 마커 이미지(p_1~p_4), 퍼즐 완성 이미지.
- **`ar-scene/image-targets/`** — 퍼즐 마커 인식 데이터(JSON), 재생성 방법은 그 안의 README 참고.

## 기술 스택

- 빌드 도구 없는 순수 HTML/JS 정적 사이트.
- **AR 엔진**: [8th Wall](https://8thwall.org/) 오픈소스 엔진(`@8thwall/engine-binary`, jsdelivr CDN).
  2026-02-28부로 유료 클라우드 플랫폼(Studio/계정 시스템)은 폐기됐지만, 엔진 자체는 API 키/계정 없이
  무료로 계속 배포된다("제한된 사용 라이선스" — 저작권 고지 유지, 리버스엔지니어링/수정 금지 조건).
  이미지 트래킹(퍼즐)과 월드 트래킹/SLAM(쓰레기줍기)에 모두 사용.
- **손 인식**: [MediaPipe Hands](https://developers.google.com/mediapipe) (Google, 무료). 별도
  카메라 스트림을 열지 않고, `XR8.CameraPixelArray`로 8th Wall이 이미 받아오는 카메라 프레임을
  그대로 넘겨받아 쓴다(월드 트래킹과 손 인식이 카메라 하나를 공유).
- 배포: GitHub Pages (정적 파일이라 별도 서버 불필요, HTTPS는 카메라 권한을 위해 필수)

## 로컬 실행

```
npm install
npm run dev
```

카메라 기능은 HTTPS가 아니면 브라우저가 권한을 안 준다. PC에서 띄운 걸 폰으로 테스트하려면
`npx localtunnel --port 8080` 같은 터널링 도구로 HTTPS 주소를 만들어 접속하면 된다.
